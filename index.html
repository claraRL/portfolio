Jeu du Pendu Graphique

Contexte : Projet de programmation (IN200 - UVSQ) | Équipe : 4 personnes

Objectif du projet :
Développer un jeu du pendu interactif doté d'une interface graphique (IHM) complète, permettant de jouer seul contre l'ordinateur avec plusieurs niveaux de difficulté.

Mes réalisations & Solutions techniques :

  • Conception de l'IHM : Développement de l'interface utilisateur avec fenêtres, menus déroulants de configuration et boutons interactifs.
  • Logique algorithmique : Traitement des chaînes de caractères pour la sélection aléatoire d'un mot dans un dictionnaire externe et détection des lettres saisies.
  • Gestion des états du jeu : Création d'une architecture propre séparant la logique du jeu et l'affichage (mise à jour des scores, système d'indices, et tracé progressif du dessin du pendu à chaque erreur).

Compétences mises en œuvre :
Python Interface Graphique (IHM) Algorithmique
Gestion de fichiers (.txt / .csv) Git / GitHub
